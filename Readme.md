# Written answer Scan AI

MVP para evaluación automática de respuestas manuscritas.

## Problema

Lirmi Scan permite corregir preguntas de selección múltiple.

Actualmente las preguntas de desarrollo requieren corrección manual.

## Objetivo

Permitir:

1. Capturar respuesta manuscrita.
2. Extraer texto mediante IA multimodal.
3. Evaluar respuesta contra pauta.
4. Generar puntaje y feedback.

## Stack

- Next.js
- NestJS
- Gemini API
